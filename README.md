# WinAPI-calculator

## Задание
Реализовать полноценный калькулятор. 
Два состояния (инженерный-обычный) меняются по выбору пункта меню.

## Описание

Учебный проект — калькулятор для Windows, написанный на C++ с использованием чистого WinAPI (без MFC и сторонних UI-библиотек). Окно и все элементы управления (кнопки, поле ввода, меню, диалоговые окна) создаются напрямую через функции Win32 API.

### Функциональность

- Стандартный режим: базовые арифметические операции (+, -, *, /), смена знака, извлечение квадратного корня, очистка поля ввода.
- Инженерный режим: дополнительные кнопки — возведение в степень (`pow`), синус, косинус, тангенс (углы в радианах).
- Переключение между обычным и инженерным режимом через пункт меню — при переключении окно перестраивается и появляются/скрываются дополнительные кнопки.
- Модальное диалоговое окно «О программе».
- Немодальное диалоговое окно (например, «Спонсорам»).

### Технологии

- C++
- WinAPI (Win32 API): окна, сообщения (`WM_CREATE`, `WM_COMMAND`, `WM_TIMER`), меню, модальные и немодальные диалоги
- Microsoft Visual Studio (проект `.vcxproj`)

### Структура проекта

```
calculator/
└── calculator/
    ├── win_main.cpp              # Точка входа, оконная процедура, логика калькулятора
    ├── calculator.rc               # Ресурсы: меню, диалоги
    ├── resource.h                   # Идентификаторы ресурсов
    ├── calculator.vcxproj            # Файл проекта Visual Studio
    └── calculator.vcxproj.filters     # Фильтры файлов проекта
```

### Сборка и запуск

Проект собирается в Microsoft Visual Studio:

1. Открыть `calculator/calculator.vcxproj` (или решение, если оно есть) в Visual Studio.
2. Собрать проект (Build → Build Solution).
3. Запустить полученный `.exe` файл.

Проект предназначен для запуска только под Windows, так как использует WinAPI напрямую.
